{{- if .Release.IsUpgrade }}

── Upgrades ──

Upgrades are forward-only. Before an upgrade, back up PostgreSQL and the
object storage bucket: rolling back is a restore of both backups together
with the previous chart version, not a `helm rollback`.
{{- end }}

{{- if .Values.zitadel.bundled }}

── Zitadel Initialization ──

The zitadel-init Job will run automatically and:
  1. Create the StackWeaver organisation, project, and OIDC apps
  2. Create service users and PATs
  3. Configure webhooks and IdP sync
  4. Write all credentials directly into the Zitadel secret
  5. Trigger rolling restarts of the API and frontend

No manual steps are required. To monitor progress:
  kubectl logs -f job/{{ include "stackweaver.fullname" . }}-zitadel-init
{{- end }}

Platform administrators are set by `platform.admins` (by default the bundled
Zitadel's bootstrap admin); they manage the installation under Settings, Platform.

For documentation: https://github.com/stackweaver/stackweaver
